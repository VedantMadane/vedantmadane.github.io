# Meter and purity reference

## अनुष्टुभ्

Four pādas of 8 akṣaras. Blog prints as **two lines** (pādas 1–2 and 3–4):

```
XXXXXXXX ।   # line 1 = 16 akṣaras (+ danda)
XXXXXXXX ॥n॥ # line 2 = 16 akṣaras
```

Gate: each line body 14–18 akṣaras after stripping danda/numbers; prefer 16.

## उपजाति

Four pādas of **11** akṣaras (triṣṭubh family), one pāda per line.

## Loan blacklist (non-exhaustive)

Do not put in verse lines: `API HTTP TLS SQL CPU CDN WAL CDC JWT OOM RPO RTO JIT BFF`
`टोकन् हैश बैच कनारी आउटबॉक्स स्नैप ब्राउजर् फ्सिन्क्` and ASCII digits.
