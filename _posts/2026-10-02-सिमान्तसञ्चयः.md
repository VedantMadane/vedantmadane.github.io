<div class="prose-text" markdown="1">

### ग्राह्यम् / Keep
१. **emit correct cache headers**: shared versus browser ages  
२. **fingerprint static assets**: short HTML entry  
३. **active purge by path or tag**: TTL alone is slow  
४. **private or Vary-keyed auth**: never leak one user to another  
५. **protect origin IPs**: edge is not full security  
६. **watch hit ratio and purge fails**: release with new asset hashes  

### त्याज्यम् / Avoid
- cache personalized JSON as public  
- TTL-only emergency fixes  
- treat edge as the only shield

सिमान्तसञ्चयः मित विद्धि हि ।
सदा भार विद्धि सदा सम्यक् ।
धर्म सम्यक् वर्धय हि सम्यक् ।
मित एकतः पश्य हि सम्यक् ।

**Word-for-word**

| संस्कृतपदम् | Word-for-word English |
| :---- | :---- |
| आन्तरसञ्चयः | inner cache |
| भिन्नः | different |
| सिमान्तस्मृतिः | edge memory |
| मार्जनोपायौ | two purge tools |
| उभे स्मृती | both memories |

**Gloss table**

| पदम् | अर्थः / sense |
| :---- | :---- |
| आन्तरसञ्चयः | app cache |
| सिमान्तस्मृतिः | edge memory |

**English sense**  
Application caches and edge caches are different tiers with different invalidation tools. Do not tune one and ignore the other.


**Context / topic**  
Topic: two tiers.


**सन्धिः**: गर्भस्मृतिः *सञ्चयधर्मः*; सिमान्तः *अत्र*।
