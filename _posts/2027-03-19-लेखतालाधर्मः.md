### What this post is about
Write-lock dharma is honest single-writer order. Take the lock before two writers meet, hold only measured time, release on success and destroy locks that never die.

### Topics
1. Why take a write lock
2. Hold lock only measured time
3. Method: hold release time
4. Release when write is done
5. Lock before dual write
6. Write the lock bound first
7. Name the failure
8. Burn dead locks on a beat
9. Not endless-lock pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
लेखतालाधर्मः = dharma of the write lock.

### ग्राह्यम् / Keep
१. **take lock before dual writers meet**: lock  
२. **hold lock only measured time**: time  
३. **release lock when write is done**: release  
४. **burn locks that never free**: burn  
५. **write a lock time bound first**: bound  

### त्याज्यम् / Avoid
- Write without a lock when two paths meet  
- Hold locks without a time bound  
- Never release after success  
- Leave dead locks forever  
- Hide lock faults from operators
