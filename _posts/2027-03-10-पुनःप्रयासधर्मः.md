### What this post is about
Bounded-retry dharma is honest recovery under load. Cap attempts, keep the same request seed, insert backoff, name failures and stop when the work succeeds.

### Topics
1. Why bound the try
2. Do not rush the second try
3. Method: bound seed pause
4. Same seed on retry
5. Pause between tries
6. Write the try limit first
7. Name the failure
8. Stop when done
9. Not endless pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
पुनःप्रयासधर्मः = dharma of bounded retry.

### ग्राह्यम् / Keep
१. **cap retry count before dialing**: bound  
२. **keep the same request seed**: seed  
३. **insert backoff between tries**: pause  
४. **name each failure class**: name  
५. **stop when the work succeeds**: stop  

### त्याज्यम् / Avoid
- Retry without a written limit  
- Change seed on every try  
- No backoff under pressure  
- Hide failure class from operators  
- Keep retrying after success
