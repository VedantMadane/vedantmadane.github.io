### What this post is about
A **सम्बन्धकुण्डम्** is a measured set of live seats. A new handshake on every ask is how time dies.

### Topics
1. Handshake time dies without a pool
2. Bound the seat count
3. Evict the idle dead
4. Validate before give
5. Method of a seat
6. Return the seat
7. Household cap
8. Wait under a clock
9. Cache is not a pool
10. Seat versus memory
11. Five limbs
12. Close

### English
Minimizable; Sanskrit-first; pure padya.

### ग्राह्यम् / Keep
१. **bound pool size**: not an endless handshake  
२. **evict idle seats**: a dead seat hits people  
३. **validate before lend**: return the seat at end of work  
४. **wait under a clock**: do not queue forever  

### त्याज्यम् / Avoid
- open a new connection on every request  
- leak seats and never return  
- one tenant eats the whole pool
