### ग्राह्यम्
१. **सूत्रकालः**: every outbound call has a timeout.  
२. **अन्त्यकालः**: caller deadline bounds the whole tree.  
३. **सोपानप्रचारः**: remaining budget shrinks down the stack.  
४. **रद्दीकरणम्**: cancel work when budget is gone.  
५. **स्थूलसूक्ष्मम्**: connect timeout ≠ read timeout ≠ total.  
६. **पुनर्यत्नसन्धिः**: retry only inside remaining deadline.  
७. **मापनम्**: time out must be visible as a distinct class.

### त्याज्यम्
- infinite default client timeouts.  
- one global 30s for every path as doctrine.  
- ignoring cancellation and leaking work.  
- retry that starts after the user already left.

**पदच्छेदः**  
कालदोषः यदि गूढः मिश्रः अन्यैः दोषैः नो ज्ञायते मूलम् ।
पृथक् संकेतः पठ्यतां लोके ततः सुबुद्धिः योजयेत् अस्त्रम् ॥

| पदम् | अर्थः |
| :---- | :---- |
| कालदोषः | timeout as error class |
| गूढो मिश्रः | hidden inside generic failure |
| पृथक् संकेतः | distinct metric/log label |
| अस्त्रम् | right mitigation tool |


**सन्धिः**: without a timeout signal you cannot tune limits, breakers, or capacity.

**वृत्तमिति**: एकादशाक्षराः पादाः।
