१. **कोशः**: secret store not chat/email  
२. **भ्रमणम्**: rotation before leak ages  
३. **न्यूनधिकारः**: least privilege scope  
४. **निवेशः**: inject at runtime not bake forever  
५. **लेखापरीक्षा**: access audit  
६. **विच्छेदः**: revoke path  
७. **पृथक्करणम्**: env and tenant isolation  

### त्याज्यम्
- secrets in git images tickets  
- never rotate  
- shared root password forever
