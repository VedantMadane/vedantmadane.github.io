### ग्राह्यम्
१. **सीएपी-त्रिकम्**: सुसङ्गतिः, उपलब्धिः, खण्डसहिष्णुता; द्वयमेव युगपद् दृढम्।  
२. **सुसङ्गतिसोपानम्**: तात्कालिकैक्यदृष्टिः, क्रमिकता, अन्त्यसुसङ्गतिः।  
३. **द्विचरणसमर्पणम्**: परीक्षा / समर्पणम्; समन्वयिबिन्दोर्दुर्बलता।  
४. **बहुपक्षन्यायः**: प्रस्तावः, स्वीकृतिः, निर्णयः; बहुमतलेखः।  
५. **प्लवन्यायः**: नेतृनिर्वाचनम्, लेखपङ्क्त्यनुकृतिः, कालपक्षः।  
६. **गणपूर्तिः**: पठनलेखनगणः; योगे संख्यानामधिक्ये दृश्यसङ्गतिः।  
७. **अनुकृतिभेदाः**: समकालासमौ; निरोधचिह्नम्; पुनरावृत्तिनिर्दोषता।

### त्याज्यम्
- विक्रेताविशिष्टसङ्ख्याः, क्षणिकमेघमूल्यानि।  
- पूर्णप्रमाणलेखानां पङ्क्तिशः अनुवादः. सार एव गृह्यते।  
- पूर्वपद्येषु गताः सङ्केतलघूकारवार्ताप्रवाहरूपरेखाः।

**पदच्छेदः**  
वितरितेषु यन्त्रेषु सम्मतिः कथम् उद्भवेत् ।

| पदम् | अर्थः |
| :---- | :---- |
| वितरितेषु | विकीर्णेषु / पृथक्स्थेषु (nodes) |
| यन्त्रेषु | यन्त्रेषु / प्रक्रियासु |
| सम्मतिः | एकाभिप्रायः / consensus |
| कथम् | केन प्रकारेण |
| उद्भवेत् | उत्पद्येत |
| एकवाक्यम् | एककण्ठः सङ्कल्पः |
| शास्त्रम् एतत् | इदं प्रकरणम् |
| तन्त्ररचनानन्तरम् | तन्त्ररचनापद्यानाम् अनन्तरम् |

**व्युत्पत्तिः**  
**वितरित**: वि + √तॄ + क्त। **सम्मतिः**: सम् + √मन् + क्तिन्। **एकवाक्यम्**: एक + वाक्य (पुरा «सर्वेषाम् एकं वचनम्»; अत्र गुच्छसम्मतिः)। **तन्त्ररचना**: पूर्वतनं तन्त्रघटकशास्त्रम्।

**वृत्तमिति**: ८-८-८-८।

| पदम् | अर्थः |
| :---- | :---- |
| विफले नेतरि | नेतरि विफले सति (leader failure) |
| दोषे | संवाददोषे / message loss |

**व्युत्पत्तिः**  
**नेता**: √नी + तृच्; सप्तमी **नेतरि**। **खण्डनम्**: √खण्ड् + ल्युट्। **रूढम्**: √रुह् + क्त (प्रतिष्ठितम्)। सम्मतिर्नाम न केवला बहुवचनचर्चा, अपि तु विफलतास्वपि *स्थिरः* निर्णयः।

<details>
<summary>पदच्छेदः · शब्दार्थः · व्युत्पत्तिः</summary>

**पदच्छेदः**  
सुसङ्गतिः अवाप्तिः च खण्डसहिष्णुता त्रयम् ।  
द्वयम् एव दृढं नित्यं न त्रीणि सह साधयेत् ॥

| पदम् | अर्थः |
| :---- | :---- |
| सुसङ्गतिः | consistency (C) |
| अवाप्तिः | availability (A); उपलब्धिपर्यायः वृत्तार्थे |
| खण्डसहिष्णुता | partition tolerance (P) |
| त्रयम् | एतत् त्रिकम् |
| द्वयमेव दृढं नित्यम् | द्वे एव नितरां दृढे |
| न त्रीणि सह साधयेत् | त्रीणि युगपत् न सिद्ध्येयुः |

**सन्धिः**: सुसङ्गतिः + अवाप्तिः → **सुसङ्गतिरवाप्तिः**।

**व्युत्पत्तिः**  
**सुसङ्गतिः**: सु + सम् + √गम् + क्तिन् (वर्गीयनुनासिकः **ङ्** गकारात् पूर्वं)। **अवाप्तिः**: अव + √आप् + क्तिन्। **खण्डसहिष्णुता**: खण्ड + सहिष्णु + तल्। Brewer / Gilbert-Lynch CAP-व्यापारः।

</div>
</details>

| :---- | :---- |

| तात्कालिकैक्यम् | linearizability |
| व्यवहारसारम् | शुद्धव्यवहारस्य सारः |

**सन्धिः**: सङ्ख्या + इव → **सङ्ख्येव**।

**व्युत्पत्तिः**  
**तात्कालिक**: तत्काल + ठक्। **ऐक्यम्**: एक + ष्यञ्। Herlihy-Wing: क्रियाः एकस्मिन् वैश्विके क्रमे तात्कालिका इव।
