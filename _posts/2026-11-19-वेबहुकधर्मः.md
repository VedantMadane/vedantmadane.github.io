<div class="prose-text" markdown="1">

### ग्राह्यम् / Keep
१. **digest plus timestamp signatures**: reject spoof/replay  
२. **document at-least-once**: receiver idempotent  
३. **backoff then dead letter**: no tight loop  
४. **allowlist destinations**: block inner ranges  
५. **rotate secrets with overlap**: shape versions  
६. **ack fast process async**: receiver side  
७. **enqueue via outbox**: not the user request path  

### त्याज्यम् / Avoid
- unsigned webhook trust  
- open fetch to link-local metadata  
- call a partner path inside a checkout transaction
