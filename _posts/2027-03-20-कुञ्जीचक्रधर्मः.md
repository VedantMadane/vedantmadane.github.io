### What this post is about
Key-cycle dharma is honest rotation of sealed seeds. Turn keys on a schedule, hold dual keys during cutover, test the new key first and destroy the old only after proof.

### Topics
1. Why cycle the key
2. Drop old apply new
3. Method: cycle dual new
4. Hold dual keys on cutover
5. Test the new key first
6. Write the cycle bound first
7. Name the failure
8. Burn old only when new is proven
9. Not no-cycle pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
कुञ्जीचक्रधर्मः = dharma of the key cycle (rotation).

४. **burn old key only after proof**: burn

### त्याज्यम् / Avoid
