### What this post is about
Multi-path is mercy under single-path death. Dharma is a prepared second route, one accepted result, measured cost and honest naming of path loss.

### Topics
1. Why a second path
2. Primary read secondary guard
3. Method: arm one fruit measure cost
4. Time-bound secondary
5. Take one fruit
6. Probe path health
7. Bound the spend
8. Name path loss
9. Not single-path pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
बहुपथधर्मः = dharma of many paths (hedged failover).

### ग्राह्यम् / Keep
१. **prepare secondary before primary death**: arm  
२. **accept exactly one business result**: one  
३. **time-bound the secondary arm**: ttl  
४. **probe path health on a clock**: probe  
५. **cap hedge spend**: cost  

### त्याज्यम् / Avoid
- Only one path with no backup  
- Accept two conflicting results  
- Hedge forever with unbounded cost  
- Never probe secondary health  
- Silent primary death
