### What this post is about
Single-write dharma is honest authorship of a fact. Hold one writer, take lock when two would write, watch write fruit and never treat dual write as settled truth.

### Topics
1. Why single write
2. Hold one writer not many
3. Method: hold one watch
4. Watch write fruit
5. Lock before dual write
6. Write the write bound first
7. Name the failure
8. Guard write on proven single path
9. Not dual-write pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
एकलेखधर्मः = dharma of single write.

### ग्राह्यम् / Keep
१. **keep one writer on each fact**: one  
२. **lock before dual writers meet**: lock  
३. **watch write fruit on a beat**: watch  
४. **write a write bound first**: bound  
५. **never crown dual write as truth**: truth  

### त्याज्यम् / Avoid
- Allow many writers on one fact  
- Write without lock when pair meets  
- No write-fruit watch  
- Treat dual write as settled truth  
- Hide write faults from operators
