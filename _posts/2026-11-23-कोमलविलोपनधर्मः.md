### What this post is about
**Soft deletes** mark records deleted without immediate physical removal so undo audit and controlled purge remain possible. They are not event-sourced tombstones and they are not the write-ahead log.

### Topics
1. Mark versus hard remove  
2. Default query filters  
3. Unique keys and recreate  
4. Cascade policy  
5. Retention then hard purge  
6. Erasure beyond soft flags  
7. Cache and search invalidation  
8. Tested restore  
9. Audit actor fields  
10. Event tombstone versus row soft versus engine log  
11. Five limbs  
12. Close  

English minimizable. Pure padya.

### ग्राह्यम् / Keep
१. **filter deleted by default**: admin opt-in  
२. **design uniques for recreate**: partial indexes  
३. **explicit cascade policy**: no ghost children  
४. **timed hard purge**: no forever graveyard  
५. **erasure path hard or crypto**: when law requires  
६. **invalidate search and cache**: on soft delete  
७. **test restore end-to-end**: with audit fields  

### त्याज्यम् / Avoid
- leave soft-deleted rows in normal user lists  
- soft-only forever for erasure requests  
- undelete button never tested on children

**Word-for-word**

| संस्कृतपदम् | Word-for-word English |

**English sense**  
Hard delete in the moment erases undo and makes foreign keys scream. Soft delete marks rows deleted so support can restore and auditors can see who asked. It is a product feature with a retention clock not a way to never delete.


**Context / topic**  
Topic: why soft delete. Distinct from event-sourced tombstones as sole history and from backups alone.

**Word-for-word**

| संस्कृतपदम् | Word-for-word English |
| :---- | :---- |
| घटनासमाधिः | event tombstone |

**Gloss table**

| पदम् | अर्थः / sense |
| :---- | :---- |
| घटनासमाधिः | event tombstone |
| लेखनाग्रः | write-ahead log |

**English sense**  
Event logs tombstone domain facts. Soft delete marks row state. The write-ahead log is engine durability. Do not conflate the three layers or you will purge the wrong truth.


**Context / topic**  
Topic: series distinctions.


**सन्धिः**: स्रोत *घटना*; कोमल *पङ्क्तिचिह्न*; अग्र *यन्त्रसत्यम्*।
