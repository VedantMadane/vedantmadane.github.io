### What this post is about
After you write you often must wait until your own eyes see it. That wait is a product feature not a bug to hide.

### Topics
1. Why read-your-writes
2. Write token
3. Session stick
4. Quorum read
5. Bounded wait
6. Timeout fallback
7. UI honesty
8. Replica lag link
9. Not always strong
10. Five limbs
11. Close
12. Seal

### Sanskrit title

१. **return a token from write**: token  
२. **route follow-up reads with token**: path  
३. **cap wait with timeout and message**: UX  
४. **sticky session only when needed**: cost  
५. **document when stale is OK**: product  

### त्याज्यम् / Avoid
- Write 200 then immediate stale profile  
- Infinite wait spin  
- Sticky forever for all users  
- No token just sleep 50ms
