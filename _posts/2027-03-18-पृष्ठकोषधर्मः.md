### What this post is about
Page-cache dharma is honest fast memory of pages. Fill the store in measure, evict stale pages on a beat, keep cache true to writes and never treat endless cache as safety.

### Topics
1. Why hold a page store
2. Fill the store in measure
3. Method: hold fill truth
4. Drop stale pages on a beat
5. Keep pages true never false
6. Write the store bound first
7. Name the failure
8. Align cache on write
9. Not endless-store pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
पृष्ठकोषधर्मः = dharma of the page store (cache).

१. **fill page store in measure**: fill  
२. **evict stale pages on a beat**: evict  
३. **keep cached pages true to writes**: truth  
४. **write a store size bound first**: bound  
५. **align cache on every write path**: align  

### त्याज्यम् / Avoid
