### What this post is about
The outer box is a letter written with the business fact. Dharma is same-commit fill, clocked read, idempotent delivery and clean delete after success.

### Topics
1. Why the outer box
2. Fill with the fact
3. Method: fill read clean
4. Clocked poll
5. Same seed on retry
6. Clean after success
7. Preserve order
8. Name failure
9. Not separate side write
10. Five limbs
11. Close
12. Seal

### Sanskrit title
बाह्यपेटधर्मः = dharma of the outer box (transactional outbox).

### ग्राह्यम् / Keep
१. **fill outbox in same commit as fact**: same  
२. **poll the box on a clock**: poll  
३. **retry with stable idempotency key**: idem  
४. **delete or mark only after success**: clean  
५. **preserve send order where required**: order  

### त्याज्यम् / Avoid
- Side write after commit without box  
- Never poll the outbox  
- Delete before downstream success  
- New random key on every retry  
- Silent skip of failed sends
