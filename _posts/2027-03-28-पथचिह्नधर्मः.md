### What this post is about
Path-mark dharma is honest hop identity across services. Attach a mark on every write hop, watch mark fruit on a beat, name when marks diverge and never crown an unmarked road as known.

### Topics
1. Why mark the path
2. Attach mark on every write
3. Method: hold attach watch
4. Watch mark fruit
5. Name split marks
6. Write the mark bound first
7. Name the failure
8. Guard mark on proven path
9. Not unmarked-path pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
पथचिह्नधर्मः = dharma of the path mark (trace).
