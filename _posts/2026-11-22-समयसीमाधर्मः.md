### What this post is about
**Deadline propagation** carries a single user time budget through every service hop and cancels work when the budget or the client dies. Fixed per-hop timeouts that ignore the parent clock invent minutes the user never granted.

### Topics
1. Root budget must flow down  
2. Absolute versus stacked relatives  
3. Cancel orphan work  
4. Child inside remaining parent  
5. Wire deadline headers  
6. Queue wait is user time  
7. Distinct timeout error class  
8. Retries and hedges share one purse  
9. No infinite server defaults  
10. Breaker hedge and deadline roles  
11. Five limbs  
12. Close  

English minimizable. Pure padya.

<div class="prose-text" markdown="1">

### ग्राह्यम् / Keep
१. **pass absolute end or remaining**: not fresh extra seconds each hop  
२. **cancel children on parent death**: no orphans  
३. **child timeout inside remainder**: always  
४. **preserve deadline on the wire**: standard headers  
५. **count queue wait**: in the user budget  
६. **label deadline exceeds**: distinct from generic faults  
७. **one purse for retry and hedge**: no full reset each try  

### त्याज्यम् / Avoid
- stack a fresh timeout per hop by default  
- ignore client disconnect and finish heavy work  
- give each retry a brand new full budget

**Gloss table**

| पदम् | अर्थः / sense |
| :---- | :---- |
| परिपथः | circuit breaker |
| प्रतिरक्षा | hedge |

**English sense**  
Breakers bound hopeless tries. Deadline lineage bounds all tries. Hedges spend the same purse. Three clocks one user. Draw them on one diagram before you enable all three.


**Context / topic**  
Topic: series distinctions.


**सन्धिः**: परिपथ *मृतपथ*; सीमा *वंशकोश*; प्रतिरक्षा *सहव्यय*।
