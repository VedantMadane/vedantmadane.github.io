### What this post is about
The dead vault holds work that failed past hope. Dharma is named death, reasoned park, clocked inspection, bounded retry and never mixing live work into the corpse pile.

### Topics
1. Why a dead vault
2. Name the dead
3. Method: name retry reason
4. Bound the retry
5. Read the vault on a clock
6. Write the root cause
7. Clean the vault
8. Keep live work out
9. Not silent death
10. Five limbs
11. Close
12. Seal

### Sanskrit title
मृतकोषधर्मः = dharma of the dead vault (dead-letter queue).

### ग्राह्यम् / Keep
१. **route exhausted failures to a named vault**: route  
२. **record root cause with the corpse**: reason  
३. **bound automatic retries**: bound  
४. **inspect the vault on a clock**: inspect  
५. **never mix live jobs into the vault**: sep  

### त्याज्यम् / Avoid
- Drop failed work with no vault  
- Infinite retry without park  
- Silent dead pile with no reason  
- Live traffic in the dead vault  
- Never read or clean the vault
