### What this post is about
**API versioning** lets producers evolve request/response shapes while old clients keep working for a stated window.

### Topics covered
1. Why silent breaks destroy clients  
2. Path vs header vs media-type versioning  
3. Compatible vs breaking changes  
4. Sunset dates for old versions  
5. Measuring who still calls vN  
6. Contract tests per version  
7. Gateway routing consistency  
8. Versioned docs  
9. Unknown version errors  
10. Link to expand-contract migrations  

### Sanskrit title
**APIसंस्करणम्** = API + *saṃskaraṇam* (versioning/refinement).
