### What this post is about
Write-bound dharma is honest write capacity. Cap write before it drains the store, watch write fruit on a beat, stop when over the bound and free write only after calm proof.

### Topics
1. Why bound the write
2. Keep write measured
3. Method: bound measure watch
4. Watch write fruit
5. Stop when write is over
6. Write the bound first
7. Name the failure
8. Free write only when calm is proven
9. Not endless-write pride
10. Five limbs
11. Close
12. Seal

### Sanskrit title
लेखनसीमाधर्मः = dharma of the write bound (quota).
