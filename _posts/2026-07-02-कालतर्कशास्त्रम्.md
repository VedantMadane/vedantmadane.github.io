### ग्राह्यम्
१. **लौकिककालदोषः**: विचलनम्, NTP-सीमा; न वैश्विकं सूक्ष्मकालैक्यम्।

**पदच्छेदः**  
यः पूर्वभावः स्वगणात् भवेत् वा सन्देशयोगात् अपरम् उत्तरं स्यात् ।  
प्राक्त्वसम्बन्धः इति ब्रुवन्ति । नो चेत् द्वयं स्यात् अपि असंबद्धम् ॥

| पदम् | अर्थः |
| :---- | :---- |
| पूर्वभावः | earlier event (same process order) |
| स्वगणात् | स्वयन्त्रक्रमात् |
| सन्देशयोगात् | send→receive link |
| अपरोत्तरम् | later event elsewhere |
| प्राक्त्वसम्बन्धः | happens-before |
| असंबद्धम् | concurrent (incomparable) |

**सन्धिः**: नो + चेत् → **नो चेद्** (पादे); अपि + असंबद्धम् → **अप्यसंबद्धम्** इष्यते. अत्र **अपि असंबद्धम्** स्पष्ट्यर्थम्।

**व्युत्पत्तिः**  
**प्राक्त्वम्**: प्राच् + त्व (earlier-ness)। Lamport: → is least partial order closed under process order and message delivery.

**वृत्तमिति**: एकादशाक्षराः पादाः।

| नीत्वा | max(local, received) इत्यर्थे |
| वृद्धं विधाय | then +1 |
| पूर्वत्वे लघुता | if a→b then C(a)&lt;C(b) |
| न तु लघुनि पूर्वता | C(a)&lt;C(b) does **not** imply a→b |

**न्यायसारः**: तार्किकघटिका कारणतां **सूचयति** एकदिशि; पूर्णं कारणताज्ञानं न ददाति।

</div>
</details>

  <p class="chapter-keyword">अनुष्टुभ्</p>
  <p class="chapter-theme">प्रत्येकं यन्त्रं एकः घटकः; तुलनायां असंबद्धता दृश्या।</p>

<p class="verse-topic">श्लोकः ७ (अनुष्टुभ्)</p>
<div class="sanskrit-text sanskrit-verse-lines" data-verse-id="v7">
  <span data-line="1" data-start="" data-end="">सदिशः काल एकैकयन्त्रांशैः परिगण्यते ।</span><br />
  <span data-line="2" data-start="" data-end="">तुलनेऽसंबद्धं ज्ञेयं पूर्णकारणता तथा ॥७॥</span>
</div>
<details>
<summary>पदच्छेदः · शब्दार्थः · व्युत्पत्तिः</summary>
<div class="prose-text" markdown="1">

**पदच्छेदः**  
सदिशः कालः एकैकयन्त्रांशैः परिगण्यते ।  
तुलने असंबद्धं ज्ञेयं पूर्णकारणता तथा ॥

| पदम् | अर्थः |
| :---- | :---- |
| सदिशः कालः | vector clock |
| एकैकयन्त्रांशैः | one component per process |
| परिगण्यते | is computed (max pairwise + self+1) |
| तुलनेऽसंबद्धम् | incomparability under componentwise order |
| पूर्णकारणता | a→b iff V(a)&lt;V(b) (strict) |

**व्युत्पत्तिः**  
**सदिश**: स + दिश् (with directions/components; vector). Fidge / Mattern vector time.

**सन्धिः**: तुलने + असंबद्धम् → **तुलनेऽसंबद्धम्**।

  <h2 class="chapter-title">षष्ठं प्रकरणम्: मिश्रतार्किककालः</h2>
  <p class="chapter-keyword">वसन्ततिलका</p>
  <p class="chapter-theme">लौकिकः + तार्किकः. एकं युग्मं; बाह्यकालसदृशं, कारणतारक्षितम्।</p>

<p class="verse-topic">श्लोकः ८ (वसन्ततिलका)</p>
<div class="sanskrit-text sanskrit-verse-lines" data-verse-id="v8">
  <span data-line="1" data-start="" data-end="">लौकिकतार्किकयुगं मिश्रकालं वदन्ति</span><br />
  <span data-line="2" data-start="" data-end="">यत्रास्ति भौतिकपदं तर्कपदं च नित्यम् ।</span><br />
  <span data-line="3" data-start="" data-end="">भौतिकवृद्धौ लघु तर्कम् अथान्यथा स्याद्</span><br />
  <span data-line="4" data-start="" data-end="">वृद्धं यथा कारणता क्रमवद् बहिः स्यात् ॥८॥</span>
</div>
<details>
<summary>पदच्छेदः · शब्दार्थः · व्युत्पत्तिः</summary>
<div class="prose-text" markdown="1">

**पदच्छेदः**  
लौकिकतार्किकयुगं मिश्रकालं वदन्ति यत्र अस्ति भौतिकपदं तर्कपदं च नित्यम् ।  
भौतिकवृद्धौ लघु तर्कम् अथ अन्यथा स्यात् वृद्धम् । यथा कारणता क्रमवद् बहिः स्यात् ॥

| पदम् | अर्थः |
| :---- | :---- |
| लौकिकतार्किकयुगम् | (pt, lc) pair |
| मिश्रकालम् | hybrid logical clock |
| भौतिकपदम् | physical/wall component |
| तर्कपदम् | logical component |
| भौतिकवृद्धौ लघु तर्कम् | when PT advances, logical part stays small / resets relative |
| अन्यथा वृद्धम् | else logical counter grows (same PT bucket) |
| कारणता क्रमवद् बहिः | causality kept; order near external time |

**व्युत्पत्तिः**  
**मिश्रकालः**: मिश्र + काल। Kulkarni et al. HLC: PT-close timestamps that still respect happens-before.

**वृत्तमिति**: चतुर्दशाक्षराः पादाः (वसन्ततिलका)।

<p class="verse-topic">श्लोकः १० (उपजाति)</p>

**पदच्छेदः**  
चित्रं ह्यनेकसंस्करणयुतम् पठ्येत कालाङ्कपुराणदृष्ट्या ।  
लेखे नवं स्यात् अपि न अन्यहानिः । पृथक्कृतिः सा क्षणचित्रसंज्ञा ॥

| पदम् | अर्थः |
| :---- | :---- |
| चित्रम् | snapshot |
| ह्यनेकसंस्करणयुतम् | multi-versioned (MVCC); हि + अनेक… |
| पठ्येत | may be read |
| कालाङ्कपुराणदृष्ट्या | under an older timestamp view |
| लेखे नवम् | on write, a new version |
| नान्यहानिः | no harm to the other side (readers/writers decoupled) |
| पृथक्कृतिः | isolation |
| क्षणचित्रसंज्ञा | called snapshot isolation |

**व्युत्पत्तिः**  
**क्षणचित्रम्**: क्षण + चित्र। **संस्करणम्**: सम् + √कृ + ल्युट् (version)। **कालाङ्कः**: काल + अङ्क (timestamp)।

**वृत्तमिति**: एकादशाक्षराः पादाः।
