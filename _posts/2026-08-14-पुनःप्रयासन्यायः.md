### ग्राह्यम्
१. **पुनःप्रयासः**: only on transient faults.  
२. **घाताङ्कविरामः**: exponential backoff.  
३. **विस्पन्दः**: jitter to desynchronize clients.  
४. **इदमर्थता**: safe retry needs idempotent ops.  
५. **प्रयाससीमा**: max attempts then fail loud.  
६. **समवर्गप्रहारः**: synchronized retry storm worsens outage.  
७. **पश्चात्प्रयासकालः**: honor server hint when given.  
८. **अन्त्यकालः**: stop retrying past the caller deadline.

### त्याज्यम्
- infinite retry loops framed as courage.  
- retrying non-idempotent payments without keys.  
- vendor SDK default names as eternal doctrine.  
- blind replay of 4xx validation failures.

| पदम् | अर्थः |

| पदम् | अर्थः |
| :---- | :---- |

| तदा क्षयः | cascading failure |
| भेदकः कालः | desynchronized schedule |
| यथाकुलम् | the whole fleet of clients |

<div class="sanskrit-text sanskrit-verse-lines" data-verse-id="v10">

  <span data-line="2" data-start="" data-end="">तं मानयेद् यत्नवतां प्रधानम् ।</span><br />
  <span data-line="3" data-start="" data-end="">सीमाविरुद्धं पुनरुद्धतं च</span><br />

<details>
<summary>पदच्छेदः · शब्दार्थः · व्युत्पत्तिः</summary>
<div class="prose-text" markdown="1">

**पदच्छेदः**  
निषेधकालं यदि सूचयन्ति तं मानयेत् यत्नवतां प्रधानम् ।
सीमाविरुद्धं पुनः उद्धतं च स्वयं विनाशाय भवेत् यतिः हि ॥

| पदम् | अर्थः |
| :---- | :---- |
| निषेधकालम् | Retry-After / wait hint |
| मानयेत् | honor the server |
| सीमाविरुद्धं यतिः | retry that fights the limit |
| विनाशाय | self-defeating load |


**सन्धिः**: सीमादरः says *stop*; पुनःप्रयासः says *return later*. Fighting 429 is not resilience.

**वृत्तमिति**: एकादशाक्षराः पादाः।

</div>
</details>
